点击 Agent 头像打开最近选择的会话；没有时先显示空会话，第一条消息才创建。输入区的文件夹按钮可选择已有项目与会话。设置中可配置 Agent 展示、默认 Agent、消息通道和保活。用户原来排队的未发送任务不会因接入升级而被悄悄重发，可明确继续或取消。

手机发送 `/agent` 查看状态，使用 `/agent codex`、`/agent claude`、`/agent cursor`、`/agent grok`、`/agent opencode` 或 `/agent hermes` 选择 Agent；`/project`（兼容 `/projects`）显示编号与项目名称，回复 `01`、`02` 选择后自动显示该项目的会话，继续回复编号选择会话。`/sessions` 查看当前项目会话，`/sessions all` 查看全部，`/more` 翻页并连续编号。没有项目时直接列出会话；没有会话时下一条消息新建。列表在原通道内有效，10 分钟或当前目标变化后失效；普通文字退出编号选择，已选会话后数字也是聊天内容。

其他命令：`/project none`、`/new`、`/status`、`/continue J…`、`/cancel J…`、`/stop J…`、`/approve A…`、`/deny A…`。停止、继续、取消和审批允许发起该任务的同一通道或 Mac 本机操作。内部 `/project P…` 与 `/use S…` 保留给本机选择器使用。

新绑定完成时，命令指南与绑定记录在同一事务中保存，再通过原通道自动发送。微信若缺少回复上下文，等待已绑定用户首条来信；iMessage 在连接就绪后发送。指南解释项目、会话、分页、任务与审批编号，`/help`返回同一内容；不推荐尚未实现的重试命令。重启和重连不会重新生成指南，解绑取消待发指南，重新绑定会生成一份新的指南。旧版本已有绑定不会因升级补发，可主动查看帮助。

Cursor、Grok、OpenCode、Hermes Agent 已接入原生 ACP，会话列表以运行时提供的范围为准，恢复时核对原 ID。自动检测不发推理请求；账号、额度和模型服务仍可能阻止执行，失败后显示执行异常，旧任务不会自动重发。Claude Chat、Cowork、Telegram、WhatsApp 尚未接入。
